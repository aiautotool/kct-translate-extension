Cài đặt bản extension local.

Bản hiện tại có thể load trực tiếp vào Chrome ở chế độ Developer. Sau khi cài, bạn chỉ cần mở một website bất kỳ và bôi đen văn bản để dùng.

  1. Mở Chrome và truy cập chrome://extensions.
  2. Bật Developer mode ở góc phải phía trên.
  3. Chọn Load unpacked rồi trỏ tới thư mục kct-translate-extension.
  4. Bôi đen từ hoặc câu trên website để hiện popup dịch, hoặc dùng phím tắt Ctrl/Command + Shift + T.

Thiết kế cho dữ liệu học tập cá nhân.

KCT Translate ưu tiên lưu dữ liệu ngay trên trình duyệt của bạn và chỉ gọi API khi cần dịch hoặc giải thích AI.

Lưu local

History, vocabulary, favorite và cache bản dịch được lưu bằng chrome.storage.local.

Không theo dõi

Extension chỉ đọc nội dung bạn chọn để dịch, không cần backend theo dõi hành vi duyệt web.

API key do bạn quản lý

OpenAI API Key cho AI Explain được nhập trong trang Settings và lưu ở trình duyệt.
